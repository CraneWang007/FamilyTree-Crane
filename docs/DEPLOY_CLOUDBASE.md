# 微信云托管部署说明（云托管 + CFS + 网页同域）

本文说明如何把当前项目部署到微信云开发（云托管），采用最小改动方案：

- 一个 Flask 容器同时提供网页、接口和照片，访问域名统一，无跨域问题。
- SQLite 数据库与上传照片放在 CFS（文件存储）挂载目录 `/data`，容器重建不丢数据。
- 小程序请求同一个云托管 HTTPS 域名。
- 本地开发方式不变：未设置环境变量时仍使用 `data/family.db` 与 `static/uploads`。

## 一、新增文件

| 文件 | 作用 |
| --- | --- |
| `Dockerfile` | Python 3.12 + 依赖 + gunicorn 启动 |
| `docker-entrypoint.sh` | 首次部署初始化数据库与照片，然后启动 gunicorn |
| `.dockerignore` | 排除小程序、文档、备份库等无关文件 |
| `requirements.txt` | 新增 `gunicorn` |

`app.py` 已支持以下环境变量覆盖：`DATA_DIR`、`DB_PATH`、`UPLOAD_DIR`、`PORT`；并在导入时自动执行 `init_db()`，适配 gunicorn 等 WSGI 启动方式。

## 二、环境变量

在云托管「服务设置 → 环境变量」中配置：

| 变量 | 建议值 | 说明 |
| --- | --- | --- |
| `DATA_DIR` | `/data` | CFS 挂载目录，数据库与照片都放这里 |
| `PORT` | `80` | 云托管默认监听端口，需与容器端口一致 |
| `WECHAT_APP_ID` | 小程序 AppID | 微信登录用 |
| `WECHAT_APP_SECRET` | 小程序密钥 | 微信登录用，务必配置为密钥变量 |
| `WORKERS` | `1` | SQLite 单进程写，不要调大 |
| `THREADS` | `8` | 并发线程数 |
| `TIMEOUT` | `120` | Excel 导入导出耗时较长 |

可选：`UPLOAD_DIR`（默认 `/data/uploads`）、`DB_PATH`（默认 `/data/family.db`）。

## 三、部署步骤

1. **开通云开发与云托管**
   微信开发者工具 → 云开发 → 云托管（或腾讯云 CloudBase 控制台），按提示开通。

2. **创建 CFS 文件存储**
   腾讯云控制台 → 文件存储 CFS，选择与云托管相同的地域（如上海），网络与云托管处于同一 VPC，记下文件系统 ID。

3. **新建云托管服务**
   - 部署方式：本地代码上传，目录选择项目根目录 `d:\Python\FamilyTree`（包含 `Dockerfile`）。
   - 端口：`80`。
   - 实例数量：最小 `1`、最大 `1`（SQLite 必须单实例）。
   - 规格：0.5 核 1G 起步；经常导入导出 Excel 建议 1 核 2G。

4. **挂载 CFS**
   服务设置 → 存储挂载 → 选择刚创建的 CFS → 挂载路径填 `/data`。

5. **配置环境变量**
   按上表配置，至少需要 `DATA_DIR=/data`、`PORT=80`。

6. **部署并验证**
   等待构建完成后，用控制台「公网访问」地址打开：

   - `https://<云托管域名>/login` 返回登录页
   - 登录后成员列表、四支亲戚谱、照片均正常

7. **小程序切换域名**
   - 修改 `miniprogram/config.js` 中 `trial`、`release` 为云托管 HTTPS 域名（不带末尾 `/`）。
   - 小程序后台 → 开发管理 → 开发设置 → 服务器域名：把该域名加入 `request` 合法域名与 `uploadFile` 合法域名。
   - 本地开发时 `develop` 仍可保留局域网地址。
   - 正式发布前，按控制台提示确认默认域名是否可用；如不允许，则在云托管绑定已备案的自有域名。

## 四、数据初始化与更新

入口脚本的规则：

- 仅当 `/data/family.db` **不存在**时，才把镜像内的初始库 `seed-data/family.db` 复制过去。
- 仅当 `/data/uploads` 为空时，才复制镜像内的初始照片。

因此：

- 服务重启、重新部署新版本**不会覆盖线上数据**。
- 重新部署也**不会自动带入**本地新数据。若要把本地最新库同步到线上：
  1. 停止云托管服务（或缩容到 0）；
  2. 在一台与 CFS 同 VPC 的 CVM 上挂载该 CFS，替换 `/data/family.db`（建议先备份线上库）；
  3. 启动服务。
- 照片增量同理，放入 `/data/uploads`。

## 五、备份

- CFS 层面：使用腾讯云 CFS 快照或定期把 `/data` 打包下载。
- 应用层面：项目现有 `data/backups/` 手工备份机制不适用于容器内部，线上备份请以 CFS 为准。

## 六、验证清单

- 网页：登录、成员列表、成员详情、四支亲戚谱、照片展示。
- 小程序：登录、查看四支、上传照片、导出 Excel。
- 运维：重启服务后数据仍在；新增成员后再次重启仍存在。
- 安全：`WECHAT_APP_SECRET` 只配置在环境变量中，不写入镜像或仓库。

## 七、常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 502 / 健康检查失败 | 容器监听端口与环境变量 `PORT` 不一致，保持两者都是 80 |
| 照片 404 | `UPLOAD_DIR` 未指向挂载目录，或 CFS 未挂载到 `/data` |
| 重启后数据回到旧状态 | 未设置 `DATA_DIR=/data`，数据写进了容器临时层 |
| `database is locked` | `WORKERS` 大于 1，改为 1 |
| 图片/数据库权限错误 | CFS 挂载目录权限不足，检查挂载点权限与运行用户 |
| 构建很慢 | `Dockerfile` 已使用国内 PyPI 源，可换用其他可用源 |
